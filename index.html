Lua in Kernel
Docs GitHub

Script the Linux kernel with Lua.

Lunatik runs Lua inside the Linux kernel: scripts that filter packets, watch processes and serve devices, loaded and stopped from the command line. The projects below build it and what goes around it.

Read the docs Lunatik on GitHub

Projects

  • Lunatik

    The framework for scripting the Linux kernel with Lua: the runtime, the bindings of the kernel's facilities and the lunatik command.

    DocsSource

  • luaebpf experimental

    Lua compiled to eBPF: XDP and TC programs written as Lua functions, which Lunatik attaches to a device and which hand a packet to a kernel script.

    GuideSource

  • moontastik

    A MoonScript collection for Lunatik, with ipparse, a library that parses the network packets Lunatik's socket buffers present.

    Source

  • openwrt_feed

    An OpenWrt package feed with Lunatik, to add to an OpenWrt build.

    Source

Underneath

  • lua

    Lua in Kernel, the fork of the Lua interpreter that Lunatik builds into the kernel.

  • lunatic

    The Lua bytecode compiler built against the kernel's Lua, from the fork of luac.

  • harness

    The conventions, checks and agent workflows Lunatik and luaebpf are developed with.
